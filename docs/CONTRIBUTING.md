# Contributing | المساهمة

Thank you for your interest in contributing to Philosophy & Science Hub!

شكراً على اهتمامك بالمساهمة في مركز الفلسفة والعلوم!

## 🤝 How to Contribute | كيفية المساهمة

### Reporting Bugs | الإبلاغ عن الأخطاء
1. Go to Issues tab
2. Click "New Issue"
3. Describe the bug clearly
4. Include steps to reproduce

### Suggesting Features | اقتراح ميزات جديدة
1. Open an Issue with label "enhancement"
2. Describe the feature and its benefits
3. Discuss with maintainers

### Submitting Code | إرسال أكواد
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## 📝 Coding Standards | معايير الأكواد

- Use meaningful variable names
- Add comments for complex logic
- Follow ES6+ standards
- Test your code before submitting

## 📚 Content Guidelines | إرشادات المحتوى

- Ensure historical accuracy
- Provide sources for information
- Maintain bilingual consistency
- Use clear, accessible language

## 🌍 Bilingual Contributions

All content should be provided in both:
- **العربية** (Arabic)
- **English**

---

**Code of Conduct**: Be respectful and inclusive in all interactions.
